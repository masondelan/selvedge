---
description: Recent Selvedge change events, optionally filtered (e.g. --since 7d, --entity users, --changeset add-billing).
argument-hint: [filters...]
allowed-tools: Bash(selvedge-cli:*)
---

Run `selvedge-cli history $ARGUMENTS` and report the recent change events. Read-only. With no arguments, `selvedge-cli history` shows the latest events.
